# BMail

A basic and incomplete implementation of the **Simple Mail Transfer Protocol**. 
The project is still a work in progress and was started as a learning project.

[CPPLib Repo](https://github.com/BrandonZ3/CPPLib) is a dependency of this project.

This project is still a work in progress.

---

## Getting Started
1. Clone the repo  
2. Build in Visual Studio  
3. Run the server  
4. Connect via an SMTP client or use my [Command](https://github.com/BrandonZ3/Command) Repository.

Right now port 8081 is being used, and cannot be changed.
This will be updated in the future.
